Privacy policy / 隐私政策

Finalized: October 4, 2026.
定稿日期：2026 年 10 月 4 日。

Scope / 适用范围

This policy concerns ScrapYardVR by HYFAI Studio, including local game data, Meta platform services, support email and this website.

本政策涉及 HYFAI Studio 的 ScrapYardVR，包括游戏本地数据、Meta 平台服务、客服邮件和本网站。

Local game save / 设备本地存档

The game saves money, completed orders, unlocked devices, tool upgrade level, tutorial completion, discoveries, collectibles, and audio, handedness, comfort, movement and language preferences. It stores these on the device to retain progress and settings. The in-game reset option deletes the local save file.

游戏在设备本地保存金钱、已完成订单、已解锁设备、工具升级等级、教程进度、发现与收藏，以及音量、惯用手、舒适度、移动和语言设置，用于保留进度与偏好。游戏内重置选项会删除本地存档文件。

Meta authorization / Meta 授权

On Quest, the game attempts to initialize Meta Platform and request an entitlement check. It uses the returned result to allow or block access. The checked game code does not request or save a Meta user ID. Meta may process account, device and authorization information under its own policies; the absence of a game-side user ID request does not mean no platform data is processed.

Quest 版本会尝试初始化 Meta Platform 并请求检查应用使用授权，以返回的检查结果决定是否允许进入游戏。已检查的游戏代码不请求或保存 Meta 用户 ID。Meta 可能依其政策处理账号、设备及授权信息；游戏代码未请求用户 ID 不表示平台完全不处理数据。

Meta system Cloud Backup / Meta 系统云备份

Automatic Cloud Backup is enabled for the app in the Meta developer dashboard. Depending on app configuration, your settings and platform conditions, Meta may back up eligible app data, potentially including the local save. Backup creation, restore and the exact files included have not been tested for this build. A local save is not necessarily synchronized immediately or after every write. The game does not operate its own cloud server.

Meta 开发者后台已为本应用启用 Automatic Cloud Backup。Meta 可能依据应用配置、用户设置及平台条件备份符合条件的应用数据，其中可能包括本地存档。本候选版本尚未实测备份生成、恢复或实际包含哪些文件。本地存档不保证每次写入后立即同步；游戏没有自建云服务器。

Other game services / 其他游戏服务

The checked game code has no game-operated account, player upload feature, game-operated server endpoint, or calls to advertising, analytics or crash-reporting services. An included SDK does not mean all its services are active.

已检查的游戏代码未见自建账号、玩家上传、自建服务器端点，或广告、统计、崩溃上报服务调用。工程包含 SDK 不等于其中所有服务均已启用。

Support email / 客服邮件

HYFAI Studio uses the support mailbox to receive and handle questions, feedback and privacy requests that players choose to send. We do not use message content for marketing or sell it. Access is limited to people who need it to handle these matters. We delete information when it is no longer needed, subject to applicable legal retention requirements. You may use the same address to request deletion of related information held by HYFAI Studio. Email providers participate in delivery and storage. Please do not send passwords, identity documents or payment details.

HYFAI Studio 的客服邮箱用于接收和处理玩家主动发送的问题、反馈及隐私请求。邮件内容不用于营销，也不出售。仅允许处理这些事务所必需的人员访问；不再需要保留时删除，依法必须保留的信息按适用要求处理。您可以通过同一邮箱请求删除开发者持有的相关信息。邮件服务商参与邮件传递与存储。请勿发送密码、证件或支付资料。

Website hosting / 网站托管

This static site adds no advertising or analytics tracking scripts. If hosted on GitHub Pages, GitHub logs visitors' IP addresses for security purposes, including visitors who are not signed in. These hosting logs are separate from in-game analytics. See GitHub's Pages documentation.

本静态网站未添加广告或分析追踪脚本。如通过 GitHub Pages 托管，GitHub 会出于安全目的记录访问者 IP 地址，无论访问者是否登录。这类托管日志与游戏内统计不同。详见GitHub Pages 官方说明。

Deletion and contact / 删除与联系

For local game data, use the in-game reset option to remove the local save. It does not delete any Meta cloud backup. To view or delete Meta-held Cloud Backups, use Meta's Cloud Backups page; backups may exist for more than one device. HYFAI Studio cannot delete Meta-held backups on your behalf. For information you sent in support email, contact 304797181@qq.com to request deletion of information held by HYFAI Studio. Uninstalling the game does not itself delete Meta cloud backups.

如需删除游戏本地数据，请使用游戏内重置选项；此操作不会删除 Meta 云备份。如需查看或删除 Meta 保管的云备份，请访问 Meta 云备份页面；不同设备可能分别有备份。HYFAI Studio 无法代您删除 Meta 保管的备份。如需申请删除工作室持有的客服邮件信息，请联系 304797181@qq.com。卸载游戏本身不会删除 Meta 云备份。
